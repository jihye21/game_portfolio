Project 01

Tint the Saver (Unity 3D 생존 시뮬레이터)

참여 역할 및 기여도

4인 팀 프로젝트에서 메인 프로그래머로 참여하여 플레이어 이동 시스템, 동물·사냥꾼 AI 및 아이템 상호작용 기능 전반을 C#으로 구현했습니다.

사용한 기술 스택
Unity C#
상황: 필드에 드랍되는 아이템의 가시성을 높이기 위해 발광 효과를 도입하고자 했습니다. 문제: 아이템마다 크기와 비율이 달라 효과를 직접 수정해야 했습니다. 해결: 아이템의 가로, 세로, 높이 중 가장 긴 값을 최댓값으로 추출하여 기준 높이로 정의하고, 이를 활용해 구의 반지름을 동적으로 계산하는 알고리즘을 설계 및 구현하였습니다. 성과: 하드코딩을 줄이고 오브젝트의 크기를 기반으로 동적 발광 효과 조절 시스템을 구축하여, 아이템 추가 및 수정 시의 휴먼 에러를 방지하고 유지보수 생산성을 크게 향상시켰습니다.
스팀 링크: Save the Tint
Project 02

C++ 기반 멀티스레드 데이터 처리

참여 역할 및 기여도

의료기기 연동 소프트웨어 프로젝트개선 및 추가 기능 구현

사용한 기술 스택
C++ Multi-thread
상황: 의료기기 BLE 연동 소프트웨어 개발 프로젝트를 진행하며, 기기와의 실시간 데이터 송수신 기능을 담당했습니다. 문제: 사용자가 버튼을 빠르게 조작하여 과도하게 데이터가 유입될 때, '데이터 입력 -> 의료기기 전달 -> 응답 수신 및 검증'으로 이어지는 긴 작업 시간 때문에 프로세스가 멈추는 성능 저하 현상이 발생했습니다. 해결: [큐] 과도하게 도입되는 요청을 큐에 추가하고 순서대로 처리하도록 하였습니다. [worker] 무거운 통신 및 검증 작업을 별도의 worker 스레드로 분리하여 메인 스레드의 부하를 막았습니다. [충돌 제어] 멀티스레드 환경에서 발생할 수 있는 공유 자원 동시 접근 충돌을 방지하기 위하여 lock을 적용하여 대기하도록 하였습니다. 성과: 빠른 버튼 입력 환경에서도 프로세스 멈춤 현상 없이 데이터 송수신을 누락 없이 안정적으로 처리하는 데 성공했습니다.

Project 03

일정 추천 서비스 웹사이트 제작

참여 역할 및 기여도

3인 프로젝트로, Socket 통신을 활용한 실시간 채팅 및 그룹 결제 연동 시스템을 구축하였습니다.

사용한 기술 스택
JAVA Socket Oracle Git
상황: 프로젝트 기획 단계에서 사장님, 사용자, 직원 등 3가지 핵심 사용자별 요구사항과 도메인 데이터를 관리해야 하는 환경이었습니다. 문제: 향후 기능 확장성과 데이터 무결성을 보장하기 위해 데이터 중복과 이상 현상이 없는 데이터베이스를 설계해야 했습니다. 해결: [요구사항 분석 및 개념 설계] 3명의 사용자 기준으로 엔티티 타입 정의서, 관계 정의서, 개념 설계 ERD를 구축했습니다. [상세 정의] 각 데이터의 속성, 식별자, 도메인을 정의하여 데이터의 표준을 수립했습니다. [테이블 정규화] 정규화 원칙을 참고하여 테이블 구조를 최적화하고, 데이터의 독립성과 무결성을 보장할 수 있도록 설계하였습니다. 성과: 기획부터 차근차근 데이터 설계를 하여 개발 진행 시 데이터 구조 변경으로 인한 리스크를 방지할 수 있었습니다.
